# Habesharon

A cinematic, responsive fashion website for Habesharon — contemporary Ethiopian clothing shaped by heritage and craftsmanship.

## Experience

- Scroll-driven horizontal runway on desktop
- Native side-swipe navigation on touch devices
- Editorial collection, story, craftsmanship and order sections
- Responsive mobile navigation
- Keyboard navigation and reduced-motion support

The site is intentionally build-free and can be hosted directly with GitHub Pages.
